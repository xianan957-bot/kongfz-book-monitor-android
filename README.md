# 孔夫子旧书网 Android 商品监控提醒工具

Android 本机网页轮询监控工具。项目范围以《孔夫子旧书网 Android 商品监控提醒工具·详细开发文档 V1.1》为准。

## 当前范围

- Android 手机本机运行，不使用服务器或云数据库
- 用户在应用内 WebView 手动登录孔夫子旧书网，并复用 WebView Cookie
- 设置关键词、作者、出版社、最高价格、品相、指定店铺（可选）、5～15 秒监控间隔
- 前台服务持续轮询孔夫子网页版搜索结果
- 本机记录当前监控会话内已处理商品，避免重复提醒
- 新商品符合条件时发送 Android 系统通知
- 点击通知打开对应孔夫子商品页
- 发现符合条件商品时尝试自动打开商品页；Android 系统若限制后台拉起 Activity，则以系统通知作为可靠入口

## 明确不包含

自动提交订单、自动付款、绕过验证码、绕过风控、服务器监控、多端同步、多账号、PC 端、管理后台、会员或收费系统。

符合条件的商品打开详情页后，会尝试触发孔夫子网页自身的“立即购买”入口并跟随网页进入结算/付款确认页面；到达确认页面后不再自动操作，最终支付仍由用户完成。若网页被 WAF 拦截或登录状态失效，则停止自动流程并保留通知入口。

## 技术说明

当前 Android 15+ 对 `dataSync` 前台服务存在后台运行时长限制，因此监控服务使用 Android `specialUse` 前台服务类型，声明用途为用户主动开启的持续商品上架监控。

孔夫子搜索监控通过官方搜索页面 WebView 轮询，使用 `sortType=3`（最新上架）读取第一页已渲染商品。作者和出版社条件分别使用官方搜索页的 `author` 与 `press` 参数，并在本地对解析出的书目信息再次筛选。解析代码集中在 `KongfzSearchClient`，便于网站结构变化时调整。用户每次手动点击“开始监控”都会建立新的本地监控会话并清空上一会话的已处理商品记录。
